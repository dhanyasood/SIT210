SIT210 Task 2.1P – Temperature and Light Data
Overview

This project uses an Arduino Nano 33 IoT to collect temperature, humidity, and light data and send temperature and light readings to ThingSpeak every 30 seconds.
This task helped me learn how to collect sensor data, connect an Arduino to Wi-Fi, send data to a cloud platform, and visualise IoT data using ThingSpea

#Program

The code uses modular functions for:

Wi-Fi connection
Reading temperature and humidity
Reading light level
Sending data to ThingSpeak
